Design a complete modern web application UI/UX for a government infrastructure monitoring platform called "Project Drishti".

Project Drishti is an evidence-driven government project monitoring and risk analysis platform. Its purpose is to help government officers identify projects that may require attention by combining project expenditure, reported progress, timelines, contractor history, inspection records, photographs, and other evidence.

IMPORTANT DESIGN DIRECTION:
Do NOT make this look like a generic AI SaaS landing page.
Do NOT overuse gradients, glowing effects, robots, AI brains, or excessive glassmorphism.
Make it feel like a serious government technology product with a clean, trustworthy, premium interface.

VISUAL STYLE:
- Modern, minimal and professional
- Light theme as the primary interface
- Deep navy blue as the main brand color
- White and very light grey backgrounds
- Blue/cyan accent for interactive elements
- Red only for high-risk alerts
- Amber for warnings
- Green for verified/normal status
- Rounded cards but not excessive
- Clean typography using Inter or Poppins
- Subtle shadows
- Strong spacing and visual hierarchy
- Use charts, maps, tables and status indicators
- Include tasteful 3D elements and subtle animations
- 3D elements should represent infrastructure, maps, data, inspection and visibility — not robots or generic AI imagery

BRAND:
Name: Project Drishti
Meaning: Drishti = vision / clear view
Tagline:
"See the Risk. Understand the Reason. Take Action."

- chart drawing animation

- constant moving backgrounds
